        Mes coins

            Un appui long (ou un clic droit) sur la carte note une trouvaille à cet endroit. Vos coins restent dans ce navigateur. Le partage crée un fichier de vos seuls coins, à envoyer à qui vous voulez ; la sauvegarde les garde tous. Pour les retrouver sur tous vos appareils ou les partager avec un groupe, voir la synchronisation.
